③ 两类接入方式

生成节点只需二选一：
· ① 第三方 API 接入：云端生图 / 生视频。默认服务商 api.seedance.nz、异步任务自动轮询，接口与 Key 复用创作台，选好「生成类型 + 模型」即可运行；也可切 OpenAI 兼容 / 百炼 Qwen / 自定义 JSON。
· ② 本地 ComfyUI 接入：本机工作流，可存多份模板，生图与生视频各用各的。
api.seedance.nz 用异步任务：生图 POST /v1/image/generations → 轮询 GET /v1/image/generations/{id}；生视频 POST /v1/videos → 轮询 GET /v1/videos/{id}。不能用 OpenAI 的复数 /v1/images/generations，否则返回 400。
生成失败时结果节点会显示接口原始返回，方便边测边调。

新画布自带一套基础工作流

每份画布首次打开时，会自动放好 ① 提示词 / ① 参考图 → ② 生成 → ③ 结果 四个节点并连好线：照着填内容、在生成节点选好引擎就能跑，不用从零搭。节点可随意改、删、拖动，也能从顶栏继续「＋」加节点。已有内容的画布不会被覆盖；若点了「清空画布」，空画布提示里可一键「↺ 放入基础工作流示例」找回这套结构。

画布怎么用

  • 提示词节点：放剧本、Seedance / MiniMax H3 生视频提示词、Midjourney / GPT Image 生图提示词。全剧资产可点「拆分」按 ▌ 自动拆成一条一节点。
  • 参考图节点：上传或拖入多张图，前端压缩到 1024 边长 JPEG；只存本机 IndexedDB。
  • 生成节点：选「① 第三方 API 接入」或「② 本地 ComfyUI 接入」后点「运行」，会自动收集所有连进来的提示词与参考图。
  • 结果节点：展示图片 / 视频 / 接口原文，可下载，也可作为下一轮参考图。

连线规则

从节点右侧圆点按住拖到另一个节点的左侧圆点即可连线；点画布上的连线可删除。生成节点只读取「连进它」的上游节点，方向别接反。

与创作台的关系

创作台 index.html 负责产出文字，本页 canvas.html 负责把文字变成图 / 视频。两个页面同源，共用一份 API 配置；创作台「⇢ 送到画布」会新开标签页，不打断正在进行的生成。

多画布切换

顶部「画布1 / 画布2 / 画布3」是快捷切换按钮，「＋ 新建画布」会按顺序新建「画布4…」；超过 3 份的在「更多画布」下拉里切换、改名（✎）、删除（×）。每份画布的节点、连线、视口独立保存；ComfyUI 地址和工作流模板是全局共享的，不用每份重复导入。「导出画布 / 导入画布 / 清空画布」都只作用于当前这一份。

两类接入方式（生成节点二选一）

① 第三方 API 接入 · 最快零配置跑通

  • 默认不用填任何东西：创作台接通大语言模型后，画布页自动复用同一份接口地址与 API Key，并把 …/v1/chat/completions 归一到域名层；生成节点默认「ZZAI / api.seedance.nz + 生图」，模型名自动推荐，直接点「▶ 运行生成」即可。
  • 生图 / 生视频切换：生成节点「生成类型」换一下即可，模型名自动跟着换成文生 / 图生版本；有参考图连入时自动用 -i2i / -i2v。
  • api.seedance.nz 是异步任务模式：生图 POST /v1/image/generations → 轮询 GET /v1/image/generations/{id}，成功读 data.result_url；生视频 POST /v1/videos → 轮询 GET /v1/videos/{id}，成功读 metadata.url。轮询已内置，不用手工配置。不要改用 OpenAI 复数路径 /v1/images/generations，网关会返回 400 invalid_request。
  • 常用模型：生图 seedream-v5-pro-t2i / -i2i、qwen-image-2.1-turbo；生视频 seedance-2.0-mini-t2v / -i2v、seedance-2.0-fast-*。模型名可随时手改。
  • 其它服务商：预设里可切「OpenAI 兼容同步生图」「阿里百炼 Qwen Image 2.1 异步生图」「自定义 JSON 接口」。切到非 seedance 预设时，请在「▸ 高级」里填该服务商的独立 API Key。
  • 「▸ 高级」可改接口地址、独立 Key、请求头、视频时长、画幅与分辨率；自定义预设还能填请求体模板与轮询路径，占位符支持 {{prompt}} {{model}} {{images}} {{content_array}} 等。
  • 结果直链是带签名的临时地址（约 24 小时），拿到后请及时下载转存。

② 本地 ComfyUI 接入

  • 只有选这一类才必须启动 ComfyUI：它要调本机 /upload/image、/prompt、/history、/view。选「① 第三方 API 接入」时，不启动 ComfyUI、不跑桥接也一样能生图生视频。左侧「测试连接」可随时确认连通。
  • 先在左侧选「生图工作流」或「生视频工作流」，再导入；可反复导入多个模板，生成节点里下拉选要用哪一个。工作流必须是「文件 → 导出工作流 (API)」格式（顶层是节点 id + class_type），普通保存格式提交会 400。
  • 导入时自动推断提示词文本节点、所有 LoadImage 参考图、各类 seed 与输出节点；不对就在映射框里改节点 id 和字段名。每次运行随机 seed，避免命中缓存；多张参考图按顺序逐张上传。
  • 想从网页一键开关：双击运行 启动漫流桥接.bat（与 manflows-bridge.py 同目录），在左侧「④ 本地 ComfyUI 工作流」展开「启停 ComfyUI」，【浏览…】选中启动 bat / exe 并保存，之后用【▶】【■】即可。桥只监听 127.0.0.1:8787，创作台与画布页共用一个黑窗口。
  • 浏览器直连需给 ComfyUI 加 --enable-cors-header "来源"；队列串行、8188 端口无鉴权，不要暴露公网；结果最多等 10 分钟。

数据与隐私

API Key、画布、参考图全部只在你本机浏览器；源码里没有任何密钥。清空画布只清画布数据，不会动创作台的历史记录。
