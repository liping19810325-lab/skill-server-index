③ 两类接入方式

生成节点只需二选一：
· ① 第三方 API 接入：云端生图 / 生视频。接口地址与 Key 复用你自己在创作台填写的配置，模型名必须自己填（页面不预置任何接口和模型）；预设只决定请求协议：异步任务（提交 → 轮询）、OpenAI 兼容同步、百炼 Qwen、自定义 JSON。

异步任务型网关的协议：生图 POST /v1/image/generations → 轮询 GET /v1/image/generations/{id}；生视频 POST /v1/videos → 轮询 GET /v1/videos/{id}。不能用 OpenAI 的复数 /v1/images/generations，否则返回 400。

生成失败时结果节点会显示接口原始返回，方便边测边调。

新画布自带一套基础工作流

每份画布首次打开时，会自动放好 ① 提示词 / ① 参考图 / ① 声音参考 / ① 视频参考（可选） → ② 生成 → ③ 结果 六个节点并连好线：照着填内容、在生成节点选好引擎就能跑，不用从零搭。节点可随意改、删、拖动，也能从顶栏继续「＋」加节点。已有内容的画布不会被覆盖；若点了「清空画布」，空画布提示里可一键「↺ 放入基础工作流示例」找回这套结构。

画布怎么用

  • 提示词节点：放剧本、Seedance / MiniMax H3 生视频提示词、Midjourney / GPT Image 生图提示词，底部三个处理按钮：
    · 「图片提示词」＝把全集 / 全剧美术资产提示词按条拆开：一条资产 = 一个节点。人物 7 条就是 7 个节点，人物四视图有几条就几个节点，场景 6 条、道具 5 条同样逐条独立；绝不把同一类资产合并成一个大节点。优先在本机直接解析（不调模型、不改原文），识别不出逐条结构时才自动调用大语言模型补标记（本地 llama / Ollama 优先，其次创作台 API）。拆前会显示各类条数供确认，原文逐字保留，原节点被替换。
    · 「SD提示词」＝调「导演分镜助手 V5（生视频提示词）」技能，按 Seedance 生视频标准调整并拆分成镜头节点；「H3提示词」＝调「导演分镜助手 V5 MiniMaxH3」技能，按 MiniMax H3 标准调整并拆分。两者都不改剧本与台词本意，新节点生成在原节点右侧、原文保留，大语言模型同样本地优先。
  • 参考图节点：上传或拖入多张图，前端压缩到 1024 边长 JPEG；只存本机 IndexedDB。
  • 声音参考节点：上传或拖入多段音频（MP3 / WAV / FLAC，建议单段 ≤ 15MB），可试听、删除，也能直接粘贴公网音频直链；同样只存本机。连到生成节点后，多参考生视频会把它作为声音参考一起提交。本地 ComfyUI：MiniMax H3 工作流不用预先接声音节点——画布会自动注入 LoadAudio 并接到 H3 的 ref_audios（上限 3 段）；含 LoadAudio 的其它工作流则直接写入载入节点。
  • 视频参考节点：上传或拖入参考视频（MP4 / MOV / WebM，最多 3 个、单个 ≤ 50MB，官方要求 MP4），可预览、删除，也能粘贴公网视频直链；只存本机。很多多参生视频模型支持「给一段参考视频，照着它的风格/运镜生成新视频」，连到生成节点后会作为 video_url 一起提交。
  • 生成节点：选「① 第三方 API 接入」或「② 本地 ComfyUI 接入」后点「运行」，会自动收集所有连进来的提示词、参考图、视频与声音参考。生成节点上直接选画幅比例 / 分辨率（生图：16:9、9:16、3:2、2:3、1:1 + 1K/2K/4K；生视频：16:9、9:16 + 0.4（864×480）/0.9（1280×736）/2.0（1920×1088）三档百万像素），生视频还可选 1–15 秒时长（Seedance 2.0 官方支持 4–15 秒，1–3 秒个别模型可能报错）。两种引擎都生效：第三方 API 走接口参数；本地 ComfyUI 对 MiniMax H3 官方模板直接写 ResolutionSelector（宽高比 + 百万像素 + 32 步进）与 duration 秒数（自动换算合法帧位），其它工作流写 Latent 宽高与帧数，留空「跟随工作流」则完全不修改原工作流。声音与视频参考也会自动上传并写进工作流：识别工作流里的 LoadAudio / VHS_LoadAudio / LoadVideo / VHS_LoadVideo 节点，把画布连入的素材上传后替换其文件字段 —— 配合 MiniMax H3 这类多参考工作流，提示词 + 参考图 + 声音 + 参考视频可以一次性全部生效。识别不到对应载入节点时会明确报错并给解决办法。
  • 浮窗预览：所有素材都能点击放大看 —— 结果节点的图片 / 视频、参考图节点的缩略图、声音 / 视频参考的条目（点名称行，视频也可双击画面）、提示词节点的「🔍 浮窗预览」按钮。浮窗内点空白处或按 Esc 关闭。
  • 结果节点：展示图片 / 视频 / 接口原文（自动按原始比例自适应显示，不拉伸变形），点图片 / 视频可浮窗放大预览（Esc 或点空白关闭），可下载，也可作为下一轮参考图。视频若因跨域 / 直链格式受限无法直接播放，点一下视频窗口会自动缓存到本地播放，连缓存也被挡时自动转下载。
  • 🖼 历史结果：顶栏「历史结果」按钮可回看之前成功生成的所有图片 / 视频（跨画布共享、只存本机，最多 60 条），点缩略图浮窗预览，可逐条下载 / 删除，也可整面板清空。blob 临时链接不会入档。

多参考素材怎么生效（异步任务型网关）

连入声音或视频参考节点、且生成类型选「生视频」时，模型会自动推荐 -multi 多模态版本；本地文件先经 POST /v1/files/upload 换成 24 小时有效的直链，再按官方文档一起写进 metadata.content：图片 {"type":"image_url","image_url":{"url":"…"}}、视频 {"type":"video_url","video_url":{"url":"…"}}、音频 {"type":"audio_url","audio_url":{"url":"…"}}。官方上限：图 ≤9 张、视频 ≤3 个（MP4，单个 ≤50MB）、音频 ≤3 段；一旦传了 content，它会整体覆盖顶层 images，所以代码会把参考图也一起转成 content 数组。多模态提示词里可用 @Image 1、@Video 1 指代素材。generate_audio 是「是否生成配音」的开关，不是声音参考，不要混用。若用本地 ComfyUI，声音/视频参考目前只作为素材留在画布上，需工作流本身带对应输入节点才能用。

鼠标与快捷键（贴近常用画布习惯）

  • 框选：在空白处按住左键拖出蓝框，框到的节点全部选中；按 Shift 拖框可追加选择，Ctrl/⌘ 或 Shift 点节点可加减单个。
  • 平移 / 缩放：按住 空格 再拖、或按 中键 拖、或按 Alt 拖可平移画布；滚轮缩放，右下角 ⌖ 回到 100%。
  • 移动：拖节点标题栏；框选多个后拖其中任一个，整组一起移动；双击标题栏可改名。
  • 撤销 / 重做：Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做，也可点顶栏 ↶ ↷。节点、连线、文字、图片、声音、位置的增删改动都能恢复；切换画布会重置历史。
  • 编辑：Ctrl+A 全选、Ctrl+C 复制、Ctrl+V 粘贴（按鼠标位置）、Ctrl+D 原地复制一份、Delete / Backspace 删除选中、方向键 微调位置（按住 Shift 一次 10px）、Esc 取消选择 / 关弹窗、Ctrl+S 立即保存。
  • 输入框 / 下拉框里打字时，除 Ctrl+S、Esc 外不触发画布快捷键，不会误删节点。

连线规则

从节点右侧圆点按住拖到另一个节点的左侧圆点即可连线。拔线：按住目标节点左侧圆点（已连线的）往外拖，线会跟着鼠标回到源头，松手在空白处＝删除，松手在别的节点＝改接；直接点连线本身也能删。生成节点只读取「连进它」的上游节点，方向别接反。快捷加节点：在画布空白处双击鼠标，弹出「添加节点」菜单，点一下就在双击位置创建对应节点（六类节点与左侧工具栏完全一致）；Esc 或点空白关闭菜单。

与创作台的关系

创作台 index.html 负责产出文字，本页 canvas.html 负责把文字变成图 / 视频。两个页面同源，共用一份 API 配置与一份本机大模型接通结果；创作台「⇢ 送到画布」会新开标签页，不打断正在进行的生成。

提示词节点调用本地大模型（任意端口 · Windows / macOS 通用）

提示词节点上的 「图片提示词」「SD提示词」「H3提示词」：「图片提示词」优先在本机直接按条解析，不调用大模型（人物 / 四视图 / 场景 / 道具逐条独立成节点）；只有文本里识别不出逐条结构时才会请大语言模型补标记。SD / H3 会先拉「导演分镜助手」技能全文再按镜头调整。只要本机开着大模型软件，这些按钮就用本地算力，不花钱、剧本不上传。

  • 和创作台共用一份接通结果：创作台「推理参数 → 本机地址 → ⚡ 自动接通」扫到的地址与模型名存在本机浏览器（manflows_local_base / manflows_local_model），两页同源，画布页直接复用。所以创作台能通，画布页的提示词节点就能通 —— 包括 9931 这类自定义端口，不再只认默认的 8080。
  • 画布页也能独立接通：左侧「② API 配置」里点 「⚡ 自动接通」，会独立扫描 127.0.0.1 / localhost 上的 9931（llama_server）、8080（llama.cpp llama-server）、11434（Ollama）、1234（LM Studio）、8000（vLLM）、5000、1337（Jan）、4891（GPT4All）、5001、8081、3000，依次探测 /v1/models、/api/tags、/health；接通后写回共用键，创作台下次打开也直接可用。也可以在创作台手填任意 http://IP:端口。
  • 支持范围：llama_server / llama.cpp llama-server / Ollama / LM Studio / Jan / GPT4All / vLLM / KoboldCpp / text-generation-webui 等提供 OpenAI 兼容 /v1/chat/completions 的软件都行；Windows 与 macOS 一样，无需额外桥接程序。请求里始终带 model 字段（探测到真实模型名就用真名，没探测到按 local）。
  • 兜底顺序：本机已接通地址 → 创作台 API 配置里你填的本机地址 → 自动扫描结果 → 默认 8080 → 创作台的云端 API。全都连不上才明确报错，每个候选的具体原因会打到浏览器控制台。
  • 连不上时按顺序查：① 模型软件的黑窗口 / 服务要一直开着；② 端口对不对（浏览器能打开 http://127.0.0.1:端口/v1/models 就说明服务在）；③ 跨域放行：llama.cpp 加 --cors-origins *，Ollama 设 OLLAMA_ORIGINS=*；④ 页面若部署在 HTTPS 主站，部分新版浏览器会拦截直连本机 http 地址，可改用本机 http 地址打开页面或做同源反代；⑤ 在左侧点一次「⚡ 自动接通」重新扫描。
  • 确认框与运行反馈：这三个按钮的确认框已改成页面内弹窗（不再是浏览器原生对话框），在预览面板 / 嵌入式窗口里也能正常弹出，不会出现「点了没反应」；点完按钮，节点里会直接显示「⏳ 正在调用本机大模型」以及失败原因（红字），不再只靠底部状态栏。技能服务器临时不可用时，SD / H3 会自动改用内置精简规则继续，不会直接失效；取消确认后按钮会立即恢复，可随时重试。
  • 只吐思考过程、正文空白：Qwen3 / Qwen3.5 一类推理模型会把生成内容放进 reasoning_content、把 content 留空。画布页已在本地请求里自动关闭 thinking（enable_thinking:false），普通模型不受影响；若仍只返回思维链，请在模型软件里关闭 thinking / reasoning 模式。

多画布切换

顶部「画布1 / 画布2 / 画布3」是快捷切换按钮，「＋ 新建画布」会按顺序新建「画布4…」；超过 3 份的在「更多画布」下拉里切换、改名（✎）、删除（×）。每份画布的节点、连线、视口独立保存；ComfyUI 地址和工作流模板是全局共享的，不用每份重复导入。「导出画布 / 导入画布 / 清空画布」都只作用于当前这一份。

两类接入方式（生成节点二选一）

① 第三方 API 接入 · 每个用户自己配置

  • 页面不预置任何接口、Key、模型名：默认全部为空。先在创作台填写你自己的接口地址与 API Key（只存你本机浏览器），画布页自动复用同一份配置并把 …/v1/chat/completions 归一到域名层；再在生成节点手动填写模型名，即可点「▶ 运行生成」。没有填接口 / Key / 模型时会明确报错提示，不会悄悄用别人的配置。
  • 生图 / 生视频切换：生成节点「生成类型」换一下即可，模型名按你要用的版本自己改（文生 / 图生 -i2i / -i2v、多模态 -multi，以你的服务商文档为准）。生成节点上可直接选画幅比例与分辨率（生图 16:9 / 9:16 / 3:2 / 2:3 / 1:1 + 1K / 2K / 4K；生视频 16:9 / 9:16 + 0.4（864×480）/ 0.9（1280×736）/ 2.0（1920×1088））和视频时长 1–15 秒。这些选项两种引擎都生效：第三方 API 按各厂商参数写法提交（生视频 metadata.ratio / metadata.resolution 与顶层 seconds；生图换算 metadata.width / height 或传 resolution；OpenAI 兼容与 Qwen 模板走派生后的 size；自定义接口用 {{ratio}} {{resolution}} {{seconds}} 占位符）；本地 ComfyUI 对 H3 官方模板写 ResolutionSelector（宽高比+百万像素+32 步进）与 duration 秒数，其它工作流写 Latent 宽高与帧数，留空「跟随工作流」就不修改原工作流。
  • 异步任务模式：生图 POST /v1/image/generations → 轮询 GET /v1/image/generations/{id}，成功读 data.result_url；生视频 POST /v1/videos → 轮询 GET /v1/videos/{id}，成功读 metadata.url。轮询已内置，不用手工配置。不要改用 OpenAI 复数路径 /v1/images/generations，这类网关会返回 400 invalid_request。
  • 模型名以你的服务商文档为准（同一个网关里生图、生视频、多模态模型通常各不相同），填错会收到接口原始报错，可在结果节点里看到。
  • 其它服务商：预设里可切「OpenAI 兼容同步生图」「阿里百炼 Qwen Image 2.1 异步生图」「自定义 JSON 接口」。切到非 seedance 预设时，请在「▸ 高级」里填该服务商的独立 API Key。
  • 「▸ 高级」可改接口地址、独立 Key、请求头；自定义预设还能填请求体模板与轮询路径，占位符支持 {{prompt}} {{model}} {{images}} {{content_array}} {{audios}} {{audio_objects}} {{videos}} {{video_objects}} 等。比例 / 分辨率 / 时长已做成生成节点上的下拉，不用进高级。
  • 结果直链是带签名的临时地址（约 24 小时），拿到后请及时下载转存。

② 本地 ComfyUI 接入 · 完整建立步骤

最简原则：不用桥接、不用额外服务。用画布前先启动 ComfyUI，然后在左侧点一下「⚡ 自动接通」，就能直接调用本机工作流 API 生图、生视频。选「① 第三方 API 接入」走云端时，完全不用启动 ComfyUI。
  1. 启动 ComfyUI：像平时一样打开 ComfyUI（本机是 Comfy Desktop，默认 http://127.0.0.1:8188）。确认浏览器能打开 http://127.0.0.1:8188 看到界面即可。
  2. 一次性允许跨域（只做一次，之后永久生效）：网页在浏览器里直连本机 8188 需要 ComfyUI 放行 CORS。给启动参数加上 --enable-cors-header *：
    • Comfy Desktop：设置 → 安装实例 → 额外启动参数 / launchArgs，写成 --enable-manager --cuda-device 0 --enable-cors-header *，保存后重启一次 ComfyUI。
    • 便携版 / .bat：在 python main.py ... 那一行末尾加 --enable-cors-header *。
    • 命令行：直接 python main.py --enable-cors-header *。
    坑：这个值必须是 * 或纯域名（如 https://www.manflows.com），不能带路径（写成 https://www.manflows.com/canvas 浏览器永远匹配不上，跨域会一直失败）。改完必须重启 ComfyUI，参数只在启动时读取。
  3. 在画布上接通：左侧「④ 本地 ComfyUI 工作流」保持默认地址 http://127.0.0.1:8188，点「⚡ 自动接通」。出现绿色的「✓ 已接通 … v0.44.2」就是通了；「测试连接」可随时复查。若你的 ComfyUI 换了端口，把地址改成实际端口再点一次即可。
  4. 导出工作流 API 文件：在 ComfyUI 里把要复用的工作流跑通一次，然后菜单「文件 → 导出工作流 (API)」存成 .json。不要用普通「保存 / 导出工作流」：那种顶层是 nodes/links 数组，提交给 /prompt 会 400；API 格式顶层是「节点 id → class_type」的对象。生图、生视频各导一份（例如本机已有的 image_qwen_image_2_1_t2i.json）。
  5. 导入画布并核对映射：左侧「导入为」选「生图工作流」或「生视频工作流」→「＋ 导入工作流 API JSON」→ 选中刚才的 .json。导入后看「当前模板节点映射」：
    • promptNodes：提示词要写到哪些节点 / 字段。有些工作流把提示词藏在 ComfySwitchNode.on_false、PrimitiveStringMultiline.value 或 TextGenerate.prompt，画布会自动把链路上找到的位置全部写一遍，避免「改了提示词却仍出默认那张图」；不对可手工增删这个数组。
    • imageNodes：所有 LoadImage 参考图，按顺序逐张上传；seedNodes：每次运行自动换随机种子，避免命中缓存；outputNodes：结果输出节点。
    • 改完点「保存映射」；「重新推断」可恢复自动识别。可反复导入多个模板，生成节点里下拉选要用哪一个。
  6. 运行生成：画布上把「提示词」「参考图」节点连到「生成」节点，生成节点引擎选「② 本地 ComfyUI 接入」、下拉选对应模板，点「▶ 运行生成」。画布会自动完成：写入提示词 → POST /upload/image 上传参考图 → 随机 seed → POST /prompt 提交 → 每 2 秒轮询 GET /history/{prompt_id} → 从 /view 取回结果。结果节点可直接看 / 下载，也能当下一轮的参考图。生视频工作流输出的 gifs / videos 会自动按视频展示。

本地 ComfyUI 常见报错

  • 「连不上 ComfyUI」/ Failed to fetch：ComfyUI 没启动，或跨域没放行（第 2 步），或画布是 https:// 而 ComfyUI 是 http://（混合内容被拦，内测期请用 http:// 本机打开）。
  • HTTP 400 / 提示 node type 不存在：导入的不是「导出工作流 (API)」格式，或工作流用到的自定义节点 / 模型在本机没装。先在 ComfyUI 里跑通再导出。
  • 提交成功但一直排队：ComfyUI 队列串行、显存不足或模型首次加载较慢；画布最多等 10 分钟。
  • 出图永远是导出的那句默认提示词：提示词没写进真正生效的节点，检查映射里的 promptNodes（第 5 步）。
  • 参考图没生效：工作流里要有 LoadImage 节点，且 imageNodes 映射到了它；图生图 / 图生视频工作流才吃参考图。
安全与边界：8188 端口无鉴权、只监听本机，不要暴露公网；正式 HTTPS 主站直连本机 HTTP 会被浏览器拦截，按正式部署阶段做同源反代 + TLS；内测期用 http:// 本机打开即可。「声音/视频参考」节点目前只作为素材留在画布上，需要工作流本身带对应输入节点才能用到本地 ComfyUI。

这些步骤可以让 WorkBuddy 代做

上面第 2～5 步都不用自己折腾，直接在 WorkBuddy 里说一句话就行。它能读你本机的文件、改启动配置、验证接口、转换工作流格式、核对映射并排错。可以直接复制下面的说法：
  • 「帮我检查本机 ComfyUI 的跨域启动参数，改成允许画布直连，并验证 8188 能通」
  • 「把 E:\comfyui 工作流api\ 里的工作流检查一遍，确认是 API 格式、提示词映射对不对」
  • 「把这份 ComfyUI 工作流转成『导出(API)』格式，并告诉我提示词该写进哪个节点」
  • 「画布连不上 ComfyUI，帮我查是没启动、跨域、端口还是混合内容问题」
  • 「帮我做一份生视频工作流的 API JSON，放到本机目录里，我直接导进画布」
WorkBuddy 只改你本机的配置和文件，画布源码里不会写任何本机路径、模型名或 API Key。

API Key、画布、参考图全部只在你本机浏览器；源码里没有任何密钥。清空画布只清画布数据，不会动创作台的历史记录。
