三、漫流 AI 剪辑台 使用说明书

漫流 AI 剪辑台已并入站点，与编导创作台、导演画布三页互通：三页顶部都有互链按钮，点一下即可切换。本页可直接读取导演画布本机生成的历史结果，把视频 / 图片一键转入素材库或当天剪辑轨道。所有素材与工程只存本机，不上传服务器。

① 板块大小可自由调整

  • 三栏之间有两条竖向分隔条，工作区与剪辑轨道之间有一条横向分隔条：鼠标按住拖动即可改变大小，相邻板块会自动补足让出的空位，整页始终填满、不留空白。
  • 调整后的尺寸记在本机，下次打开仍然保留；点顶栏「↺ 恢复初始化布局」一键回到初始尺寸。

② 素材库：拖进轨道就能剪

  • 点「＋ 导入素材」「＋ 上传本地文件」，或把文件拖进虚线框：支持文本（.txt / .md / .srt / .vtt）、图片（.png / .jpg / .webp）、视频（.mp4 / .webm / .mov）、声音（.mp3 / .wav / .m4a）。顶部 Tab 可切「全部 / 视频 / 图片库 / 音乐 / 音效库 / 文本」；切到「音乐/音效库」后可用下方子目录分别看「音乐库」「音效库」，每个声音素材卡上的 🎵/🔊 标签可一键切换归类。点「🔗 粘贴在线 URL」可一行一个粘贴在线文件地址。
  • 每个素材的预览缩略图已放大一倍，卡片上不再放演示、＋、播放、删除按钮：按住素材拖到下方对应类型的轨道即可放到鼠标落点的时间位置；双击则自动放到该类轨道的播放头处。
  • 单击选中素材（蓝色高亮），按 Delete / Backspace 删除；文本与 SRT/VTT 会自动拆成一条条字幕落到字幕轨。本地大文件只存本机 IndexedDB，不上传服务器。

③ 轨道自适应：字幕 → 图片 → 视频 → 音频

  • 轨道不再固定六条，改为按你拖入的素材类型自动生成：同类素材可以有多条轨道，拖入时优先复用该类轨道上与落点不重叠的空位，都占满了就自动新建一条同类轨道；拖到类型不符的轨道会自动改放到正确类型的轨道并提示。
  • 层级固定为最上层字幕（文本）→ 图片 → 视频 → 最下层音轨，新轨道自动插在所属分组里。字幕层不再区分对白 / 旁白 / 内心独白，全部由你自己决定放哪条字幕轨、写什么内容；单条字幕只保留一个可选「类型标签」用于颜色与 SRT 标注。
  • 轨道名右侧的 ＋ 新建一条同类型轨道、× 删除该空轨道（有片段时先删片段）；工具条「＋ 轨道」可直接选类型新建。LUT 调色轨同样可删除；删掉后如需再用，从「＋ 轨道」菜单选「LUT 调色轨」即可重新加回，或在调色 LUT 面板加载 / 应用 LUT 时自动重建。旧工程里原来的对白 / 旁白 / 内心独白三条字幕轨会自动合并成一条字幕轨，片段不丢失。
  • 跨轨拖动（新）：按住时间轴上的片段往上下轨道拖，松开时如果落点已有同类轨道就直接移进去；如果落点是别的类型轨道，会自动新建一条同类轨（如「视频 2」「音频 2」）并把片段放进去。拖动过程中落点轨道会绿色高亮并提示。片段只能在同类轨之间自由移动。
  • 主轨磁吸（新）：第一条视频素材进主视频轨时自动贴到 0 秒；「🧲 磁吸」默认开启，开启时在主轨上裁剪 / 删除 / 剪断 / 粘贴 / 拖动造成中间空档，后面的片段自动前移紧跟（波纹前移），始终保持无间隙。其它轨道不受影响，仍可自由分布。

③-2 播放器（剪映 6.0 同款）

  • 预览栏已按剪映 6.0 播放器重做：顶部只有文件名标签 + 播放器标签，画面区纯黑底无多余按钮；底部控制条左边是帧号时间码 HH:MM:SS:FF（30fps），中间是上一帧 / 播放暂停 / 下一帧，右边是比例 / 高清 / 音量 / 全屏。
  • 比例菜单可选自适应 / 16:9 / 9:16 / 4:3 / 1:1，还有「◇ 变换框」开关；高清是画质标识（跟随素材原始分辨率，不做假超分）；全屏或 F 进入 / 退出播放器全屏；底部细条可拖动定位播放头。
  • 原有的字幕 / 图片 / 视频 / 音频多层同步预览、LUT 调色、变换框、录音音量表等全部保留，只是入口收进了比例菜单或画面本身。

④ 四个 AI 按钮（剪辑轨道上方横向一排）

  • ✨ AI剪辑：点按钮先弹出「剪辑思路与模型」窗口 —— 可以写下你对这条片子的剪辑想法（节奏、删减、顺序、字幕位置等，可留空），并在下拉里选一个你已经部署好的算力里的大语言模型，建议只选 Claude 或 GPT 系列之一，下拉没有就手填模型名。点「▶ 开始 AI 剪辑」后会出现分阶段进度条：模型已调用 → 轨道素材分析中 → 视频画面抽帧中 → AI 剪辑进程中（带已等待秒数）→ 生成剪辑方案 → 完成。模型拿到整条时间轴结构、素材元信息、独立音轨、毫秒字幕、静音区间、视频抽帧与你的思路，先做语义分析区分有效停顿 / 无效废片并给出内容优化建议；确认后删除建议会转成剪口播候选（可勾选、全选、撤销），其它裁切 / 字幕优化可直接写入轨道（Ctrl+Z 可撤销）。带图请求失败会自动降级为纯轨道数据分析。Claude / 普通 GPT 这类文本或视觉对话模型就能跑，不需要语音转写能力。跨域说明：模型请求与「对话剪辑」一样优先经本机服务（127.0.0.1:8788）转发，服务会自动探测 127.0.0.1 / localhost 两个地址；双击启动本机服务即可绕开浏览器 CORS，服务离线时才尝试直连并给出明确诊断。
  • 🤖 对话剪辑（真正由大模型驱动的 AI 剪辑）：点这个按钮打开对话面板，用日常自然语言说需求即可，例如「删掉所有嗯啊语气词和长停顿」「把节奏加快」「挑出高光片段」「读取文稿并总结」。AI 会真正调用工具：先 read_timeline 读时间轴拿到准确的片段 id 和秒数，必要时 read_script 读出带 [sN] 段号的文稿，用 preview_frame 抽真实画面做视觉自检（图片会回注给模型看图），改完再自检、不对就用工具继续修正。所有编辑只生成提案，面板底部会出现「待确认的剪辑提案」卡片，列清楚每一项改动（裁片头、删片段、移动、变速、按文稿写回等），你点「✅ 应用提案」才真正写入轨道（Ctrl+Z 一步撤销），点「放弃」则时间轴分毫不动。模型需要 Claude / GPT 这类能稳定输出工具调用的强模型；模型与 Key 复用左上「算力总控」，经本机服务代理转发，Key 不会暴露给第三方页面。对话支持多轮连续编辑，复杂需求可多步完成。
  • 🅰 AI字幕：点按钮会先弹出与 AI 剪辑同款的算力 / 引擎 / 模型选择窗，可选自动探测、仅本机 faster-whisper、仅第三方转写接口，并填模型名与语言后开始。真实分析轨道上的视频 / 音频素材，绝不生成演示假字幕。现在改由本机服务（127.0.0.1:8788）转发转写：网页把素材交给服务，服务用 FFmpeg 抽成 16kHz 单声道 WAV，按 60 秒切片（每段约 1.9MB，彻底避开整段 mp4 超 20MB 的问题），逐段送转写接口，再把分段时间码合并（含毫秒级 startMs/endMs 分段与静音/气口区间数据）、对齐到片段在轨道上的位置写进字幕轨；即使转写后端不可用，静音区间也会独立返回给智能剪口播。转写后端三级自动降级：① 本机 faster-whisper（默认 9000 端口，纯本地免费）→ ② 创作台 / 画布里填的第三方 OpenAI 兼容 /v1/audio/transcriptions（由本机服务转发，绕开浏览器 CORS，不再 Failed to fetch）→ ③ 都没有则给出明确安装指引，绝不假造字幕。服务离线时才回退浏览器直连，并会区分「CORS 拦截 / 接口 404 / 连接失败」。
    模型能力说明：Claude 全系、普通 GPT / Qwen / DeepSeek 这类对话模型不是语音转写模型，也没有 input_audio 音频输入能力，能跑 AI剪辑但不能直接做 AI字幕；AI字幕需要 whisper-1 / gpt-4o-transcribe 这类转写通道，或本机 faster-whisper。
  • ✂ 剪口播：对照剪映「自动识别片段中的停顿、重复和语气词等无效片段，并支持一键删除」做的纯本地实现，不调用任何云端 VIP / 火山引擎。静音检测不依赖 Whisper：默认 -35dB、停顿 ≥0.5 秒，可自定义阈值、最短停顿与切口留白（默认 0.12 秒，删掉长静音时两侧各保留一点气口）；Whisper 失败时还能退回浏览器 WebAudio 本地分析。文本规则会抓句内语气词（啊 / 嗯 / 那个 / 就是…）与相邻相似重复句。候选逐条勾选、全选 / 全不选，一键波纹删除并可 Ctrl+Z 撤销；弹窗内有检测日志面板展示 Whisper 调用状态与静音原始数据。素材时长显示 0.00 时按钮会禁用并说明原因。删除后视频 / 音频 / 字幕 / LUT 会按同一批区间物理切成多个独立片段，没剪好的段落可继续手动裁剪、变速、倒放；导出成片仍是完整一条，由本机 FFmpeg 按各片段真实源范围拼接重编码，不是只做预览隐藏。
  • 🎨 时间轴 LUT 轨：视频轨上方新增独立的 LUT 轨。在右侧「调整 · 调色 LUT」面板加载 .cube / .3dl / .lut 文件，可保存多个预制反复调用；LUT 自带强度 / 亮度 / 对比度 / 饱和度 / 色温参数，拖动滑块实时改变画面。LUT 片段可裁剪、可移动，只影响它覆盖时间段内下方的视频；导出时由本机 FFmpeg 的 lut3d 滤镜真实烘焙进成片，预览与成品一致。
  • 🧲 磁吸 / 双向裁剪 / 变换框：时间轴工具栏「🧲 磁吸」按钮高亮=开启，点一下开/关（选择会记住）。开启后拖动片段或裁剪手柄时，靠近其它片段首尾、播放头、0 秒会自动吸附对齐，浮层显示「🧲 已吸附」；关闭则完全自由拖动。每个片段头尾各有一个可拖动手柄（鼠标移上去高亮变蓝）：向右拖开头=裁掉片头；向左拖开头=在源素材范围内找回片头（到源起点为止，拉不出界）；向左拖结尾=裁掉片尾；向右拖结尾=找回片尾（到源素材末尾为止）。裁剪时画面上方实时显示起点/终点时间码。剪刀 ✂ 按钮在手柄内侧，悬停片段才出现，点一下从播放头处剪断（等价快捷键 S）。预览窗口的移动 / 缩放 / 旋转控件默认不再常显——只有鼠标移到预览画面上才出现，也可点播放器右下「比例」菜单里的「◇ 变换框」常显。磁吸开启时主轨编辑后会自动波纹前移填满空档（详见第 ③ 节）。
  • 🎬🔊 复合音视频轨 / 波形：带声音的视频片段在时间轴上高度加倍，上半是画面、下半是音频波形；所有音频轨片段也自带波形（由浏览器 WebAudio 解码生成，不上传任何数据）。右键这类视频片段可选「拆分视频和音频轨道」，音频会下移到新音轨并与画面严格对齐，之后可单独剪辑或删除。
  • ⏺ 录音：点位录音按钮后先弹出输入选择窗，可选任一麦克风或「系统声音 / 当前标签页内录」；录音时预览画面与弹窗同时显示左右双声道实时电平表，再点顶栏「⏹ 停止录音」结束，录音文件自动加入音频轨。调用电脑麦克风，录音开始时轨道上所有声音自动静音（视频与所有音频轨），保证录进来的声音纯净；再点一次「⏹ 停止录音」结束，轨道声音立即恢复，录音文件自动加入音频轨。
  • 两栏状态彻底分开：独立的「✨ AI 剪辑」与「🅰 AI 字幕」两块运行状态栏已分别整合进点击对应按钮后弹出的浮窗里（浮窗关闭由你自己操作，点 × 或「取消」才会关）。各自显示自己的进度条与报错，点其中一个按钮只清空自己那一栏，不会再看到另一个任务残留的旧报错。AI 剪辑 / AI 字幕开始运行后浮窗保持打开，进度就在浮窗内看。

🎯 入点 / 出点区间导出：把播放头移到想要的位置按 I 设入点（标尺显示绿色 I），再移到结尾按 O 设出点（红色 O）；两点之间会高亮显示。之后点「⬆ 导出成片」，成片只导出入点到出点之间的素材（画面 / 音频 / 字幕 / GIF 都按此区间裁切，字幕时间码也平移到从入点开始）。也可用工具条「[ 入点」「] 出点」按钮设置，「✕ 清IO」或 Shift+U 清除、恢复导出整条素材。出点必须晚于入点；只设一个点或都没设时，导出回退为整条素材（到最后素材结尾）。入出点随工程一起保存。

点标尺或轨道空白处移动播放头；片段上的小剪刀可在点击位置直接剪断。预览区会同步播放主画面视频、混播所有音频轨、叠加所有图片层与字幕层。点顶栏「⬆ 导出成片」可一次勾选导出综合视频、单独音频、GIF 动图与单独字幕（原「导出字幕 SRT」按钮已并入这里）。

⑥ 从导演画布一键转入

左侧「⇢ 扫描画布生成结果」会读取本机画布的 IndexedDB 历史结果（manflows_canvas_db / canvas / __global__ / history），列出生成过的视频与图片，每项可转入素材库或直接放进当天剪辑轨道。画布结果页后续要加的转入按钮，也会走下面这个通道（三页已同域，通道现已生效）：

function sendToEditor(d, target){
  const p = { id:"cv_"+Date.now(), source:"canvas", type:d.kind,
              name:d.name||"画布生成结果", url:d.url, target:target, at:Date.now() };
  try{ localStorage.setItem("manflows_ai_editor_inbox", JSON.stringify(p)); }catch(e){}
  try{ new BroadcastChannel("manflows_ai_editor").postMessage(p); }catch(e){}
  window.open("./editor.html?fromCanvas=1","_blank");
}

剪辑台同时监听 BroadcastChannel("manflows_ai_editor")、storage 收件箱与 postMessage，也暴露了 window.ManflowsAIEditor.receiveFromCanvas(payload) 供直接调用。本地单文件预览与线上站点不同源，读不到线上画布数据时可用「模拟转入」查看效果；部署到 www.manflows.com 同目录后即自动读得到。

    倒放 / 变速是真渲染：预览可临时模拟（反向播放头 / playbackRate），导出前会由本机 FFmpeg 对每个相关片段分段重新解码、重排帧顺序、重算 PTS、对音频做时间拉伸保音调，再重编码成中间片参与合成；支持 0.25x～5x，倒放与变速可叠加，长视频按 2 秒分段处理避免内存溢出，进度条会显示每一段。
    字幕烧录：视频区块的「烧录字幕」默认开启，导出时把字幕轨交给本机 FFmpeg 的 libass 滤镜真正写进画面像素（硬字幕，支持中文），不依赖播放器外挂；关闭则只输出画面，可另在「字幕导出」里单独拿 SRT / VTT。防爆音：导出真渲染时每个片段首尾各加 30ms 淡入淡出，消除智能剪口播切段拼接处的爆音，预览逻辑不受影响。
  • 本机小服务（Mac / Windows 通用，可选）：点此直接下载（点链接即直接下载，勿用另存为网页）—— ⬇ 一键启动全部·Mac（推荐） · ⬇ 一键启动全部·Win（推荐）；仅需单个服务：Mac / Win。下载后双击即可在本机 127.0.0.1:8788 起一个纯 Python 标准库服务，零 pip 依赖、只监听本机、不上传任何素材。它负责两件事：① 把抖音 / B站等分享链接解析成可播放直链并代理视频流（带 CORS 与 Referer 处理）；② 调用本机 ffmpeg（Mac 走 VideoToolbox 硬件编码）输出 MP4 / MOV 与 H.264 / HEVC / ProRes / AV1。服务没启动时网页自动降级：链接给出明确原因、导出用浏览器自带编码。ffmpeg 官方下载：Mac https://brew.sh/ 后 brew install ffmpeg，或静态版 https://evermeet.cx/ffmpeg/；Windows https://www.gyan.dev/ffmpeg/builds/。服务启动时会检测并给出对应链接。
    每位用户用自己电脑上的 FFmpeg：Windows 可 winget install --id Gyan.FFmpeg 或下载 https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip，Mac 用 brew install ffmpeg，Linux 用 sudo apt install ffmpeg；服务也会按需自动下载静态版到 ~/.manflows/bin/。仓库里的 render_verify.py 是 10 秒短视频验证用例，可直接跑出倒放与各档变速的实测结果。

🔗 粘贴在线文件 URL

一行一个 URL，支持 视频 / 图片 / 声音 / 文本 / SRT 字幕直链；抖音 / B站等分享链接会交给本机服务自动解析成可播放视频；也可以直接粘贴一段纯文字，会存成文本素材。

网页分享链接不是视频文件：直接塞给播放器只会黑屏无声，所以现在会先识别再由本机服务解析。解析失败会明确告诉你是「防盗链 / 未开跨域 / 需要直链 / 本机服务未启动」中的哪一种，不会再生成一个黑屏素材。
在线文本文件会尝试 fetch 读取；未开跨域请改用「上传本地文件」。媒体直链（.mp4 / .webm / .mp3 / .jpg 等）可直接播放。

🅰 AI 字幕 · 算力与转写模型

✦ AI 字幕需要语音转写模型（whisper-1 / gpt-4o-transcribe / 本机 faster-whisper）。Claude、普通 GPT / Qwen / DeepSeek 等对话模型不能直接转写；本机服务会把长音频按 60 秒切片后转发，绕开浏览器跨域。转写失败时静音/气口仍会独立返回给「剪口播」。

🛠 没有转写模型？点这里：在自己电脑安装本机 faster-whisper（免费、离线，Mac / Windows 都可）
推荐：一键启动全部（8788 主服务 + 9000 转写服务，一个文件全搞定） —— ⬇ Mac 版 · ⬇ Windows 版（点链接即直接下载，勿用浏览器另存为网页；.command/.bat 结尾即正确）。首次会自动建虚拟环境、装 faster-whisper、下 460MB small 模型。
说明：8788 主服务是必开核心（导出/链接/AI剪辑/转发转写）；9000 转写服务只在 AI字幕选「本机转写」时才需要，若你用第三方转写接口则不必开。两者可分开下载：仅本机服务·Mac / 仅转写服务·Mac。
启动后回到本页把「转写引擎」选成「仅本机 faster-whisper（9000）」，点开始即可。
手动安装（可选）：pip install faster-whisper==1.2.0，然后运行 python faster-whisper-server.py。模型可用环境变量 FW_MODEL 改（tiny/base/medium/large-v3）。
