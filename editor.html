三、漫流 AI 剪辑台 使用说明书

漫流 AI 剪辑台已并入站点，与编导创作台、导演画布三页互通：三页顶部都有互链按钮，点一下即可切换。本页可直接读取导演画布本机生成的历史结果，把视频 / 图片一键转入素材库或当天剪辑轨道。所有素材与工程只存本机，不上传服务器。

① 素材库：四类本地文件 + 在线 URL

  • 点「＋ 导入素材」「＋ 上传本地文件」，或把文件拖进虚线框：支持文本（.txt / .md / .srt / .vtt）、图片（.png / .jpg / .webp）、视频（.mp4 / .webm / .mov）、声音（.mp3 / .wav / .m4a）。顶部 Tab 可切「全部 / 视频 / 图片库 / 音乐库 / 文本」。
  • 点「🔗 粘贴在线 URL」可粘贴一行一个在线文件地址，自动按扩展名判类型，也能手动指定；在线字幕 / 台词文件会尝试读取文本内容（跨域读不到时会给出提示，可改用本地上传）。
  • 每个素材点 ＋ 加入剪辑轨道：视频 / 图片进主画面或图片叠加轨，声音进音乐轨，文本与 SRT/VTT 会自动拆成一条条字幕，按对白 / 旁白 / 内心独白分到三条独立字幕层。
  • 素材点 ▶ 可单独预览，点 × 移除。本地大文件只存本机 IndexedDB，不上传服务器。

② AI 自动剪辑：语音 → 三条字幕层

  • 演示识别：用内置漫剧台词演示完整链路，选中主画面片段后点识别，自动生成带时间码的对白 / 旁白 / 内心独白三条字幕轨。
  • 本机 Whisper / 第三方 API：填任意 OpenAI 兼容的 /v1/audio/transcriptions 地址（本机 faster-whisper-server 或云端），上传选中视频 / 音频文件转写，返回 segments 的时间码后自动分类成三层字幕。跨域服务需要自己开 CORS。
  • 浏览器麦克风实时听写：实验功能，用浏览器自带语音识别把当场说的话写成字幕（Chrome 需可访问其语音服务）。
  • 分类规则可人工改：右侧字幕层里每条都能改文字、改类型、改起止时间；含「心想 / 心里 / 括号内」判内心独白，含场景 / 时间描述判旁白，其余判对白。

③ 剪辑轨道与人工剪断

  • 六条轨道：主画面·视频、图片叠加、音乐 / 声音、对白字幕、旁白字幕、内心独白。主画面轨也接受图片当静帧使用。
  • 点标尺 / 轨道空白处移动播放头；拖动片段改位置，拖右边缘裁切长度；片段上的小剪刀可在点击位置直接剪断；工具条「✂ 在播放头剪断」只剪选中片段（没选中时自动挑播放头处的片段）。视频 / 音乐 / 字幕都能剪。
  • 右侧「选中片段属性」可精确改起止时间、素材内切入点、字幕文字与类型；Delete 删除，Ctrl+Z / Ctrl+Shift+Z 撤销重做，Space 播放暂停，S 剪断，← → 微调播放头。
  • 预览区会同步播放主画面、音乐，并把三条字幕层叠加在画面上（对白白字 / 旁白黄字 / 内心独白粉字斜体）。「⬇ 导出字幕 SRT」把三层字幕合并导出。

④ 从导演画布一键转入

左侧「⇢ 扫描画布生成结果」会读取本机画布的 IndexedDB 历史结果（manflows_canvas_db / canvas / __global__ / history），列出生成过的视频与图片，每项可转入素材库或直接放进当天剪辑轨道。画布结果页后续要加的转入按钮，也会走下面这个通道（三页已同域，通道现已生效）：

function sendToEditor(d, target){
  const p = { id:"cv_"+Date.now(), source:"canvas", type:d.kind,
              name:d.name||"画布生成结果", url:d.url, target:target, at:Date.now() };
  try{ localStorage.setItem("manflows_ai_editor_inbox", JSON.stringify(p)); }catch(e){}
  try{ new BroadcastChannel("manflows_ai_editor").postMessage(p); }catch(e){}
  window.open("./editor.html?fromCanvas=1","_blank");
}

剪辑台同时监听 BroadcastChannel("manflows_ai_editor")、storage 收件箱与 postMessage，也暴露了 window.ManflowsAIEditor.receiveFromCanvas(payload) 供直接调用。本地单文件预览与线上站点不同源，读不到线上画布数据时可用「模拟转入」查看效果；部署到 www.manflows.com 同目录后即自动读得到。

⑤ 当天工程

工程按日期自动命名（如 2026-11-16），轨道与字幕自动存在本机；「💾 保存工程」手动存，「📂 打开工程」可切到其它日期，「⬇ 导出工程 JSON」可备份，「↺ 重置演示工程」回到内置示例。

🔗 粘贴在线文件 URL

一行一个 URL，支持 视频 / 图片 / 声音 / 文本 / SRT 字幕；也可以直接粘贴一段纯文字，会存成文本素材。

在线文本文件会尝试 fetch 读取内容；若对方站点未开跨域，请改用「上传本地文件」。媒体文件（视频 / 图片 / 声音）可直接用直链播放。
