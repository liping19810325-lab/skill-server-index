==========================================================
 漫流 AI 剪辑台 · 本机服务  使用说明
==========================================================

【它是什么】
一个只在你自己电脑上运行的小服务，供 https://www.manflows.com 的剪辑台
页面调用，用来：
  1）解析抖音/B站分享链接、代理播放网络媒体（解决跨域与防盗链）；
  2）调用本机 FFmpeg 把浏览器录制好的中间文件转码/导出成片、抽音频、生成 GIF；
  3）【新】给「🅰 AI字幕」和「✂ 剪口播」做语音转写：把视频抽成
     16kHz 单声道 WAV、按 60 秒切片，再转发给转写接口并合并时间码；
  4）【新】给「◀ 倒放」「变速」做真正的重渲染：分段重新解码、重排帧、
     重算时间戳、对音频做时间拉伸，再重编码成中间片交给剪辑台合成。

服务本身只用 Python 3 标准库，零第三方依赖，不需要联网安装任何 pip 包。
（AI 字幕若要走「本机 faster-whisper」这一档，才需要另外装一次，见下文。）

----------------------------------------------------------
【怎么启动】
Mac：      双击「启动本机服务.command」
           （若提示「无法打开，因为来自身份不明的开发者」：右键该文件 →
            「打开」；或在终端里先执行
            chmod +x 启动本机服务.command 再双击）
Windows：  双击「启动本机服务.bat」
           （若被安全软件拦截，选「仍要运行」）
Linux：    终端执行  python3 manflows-local-service.py

启动后会弹出一个终端窗口，打印服务信息与端口 8788。
★ 请保持这个窗口开着，不要关闭它，也不要关电脑睡眠后断网。
  浏览器里点「导出成片」或「🅰 AI字幕」时会自动探测本服务。
停止服务：在该窗口按 Ctrl+C，或直接关闭窗口。

端口：http://127.0.0.1:8788
      只绑定 127.0.0.1（本机回环），不对局域网/公网开放。

----------------------------------------------------------
【FFmpeg（导出成片 / 倒放变速 / AI字幕 都需要）】
★ 这是「每个用户各自在自己电脑上」装一次，不是网站服务器装。
   Mac / Windows / Linux 三种电脑都支持，服务会自动识别平台。★

如果本机没有 FFmpeg，第一次点「导出成片」时服务会尝试自动下载静态
FFmpeg 到 ~/.manflows/bin/（Windows 是 %USERPROFILE%\.manflows\bin\ffmpeg.exe）；
若自动下载失败，请按下面手动安装后重启本服务。导出弹窗里也会直接显示
可点击的下载地址。

官方下载 / 安装方式（三个平台都给出）：
  macOS
    Homebrew   https://brew.sh/          装好后执行：brew install ffmpeg
    静态版     https://evermeet.cx/ffmpeg/
    Apple Silicon 也可用 https://www.osxexperts.net/
  Windows
    构建包     https://www.gyan.dev/ffmpeg/builds/
    直链       https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
    备用       https://github.com/BtbN/FFmpeg-Builds/releases
    命令安装   winget install --id Gyan.FFmpeg
    手动做法   解压 zip，把 bin\ffmpeg.exe 放到 C:\ffmpeg\bin\，
               并把这个目录加进系统 PATH；或直接放进
               %USERPROFILE%\.manflows\bin\ 让服务自动找到。
  Linux
    Debian/Ubuntu  sudo apt install ffmpeg
    Fedora         sudo dnf install ffmpeg
    其他发行版     https://ffmpeg.org/download.html
  Python（运行本服务用）https://www.python.org/downloads/

AI 字幕会用 FFmpeg 把任意视频抽成 16kHz / 单声道 / 16bit 的 WAV，
每 60 秒约 1.9MB（远低于大模型 20MB 的音频上限），所以再长的片子也能识别。

----------------------------------------------------------
【倒放 / 变速导出：为什么必须装本机 FFmpeg】
网页预览里倒放是反向拨播放头、变速是临时改 video.playbackRate，
这些只是「看着像」，并没有写进文件。导出成片时如果只靠录屏改倍率，
拿到的成品时长、帧序、音画都会不对。

现在导出前会先把每个带倒放 / 变速的片段交给本机 FFmpeg：
  · 画面：setpts 重算每帧 PTS；reverse 完整反转帧顺序；
  · 音频：atempo 时间拉伸并保持音调（0.25x / 5x 会自动串联多段
          atempo）；areverse 把音频采样整段反向；
  · 长视频按每 2 秒一段处理，reverse 只缓存单段帧，
    不会把整部片子的帧一次性读进内存，避免浏览器/电脑内存溢出；
  · 每段重新编码后按输出顺序拼接，支持 0.25x～5x，
    倒放与变速可叠加（先变速、再倒放）；
  · 全程在后台线程跑，页面不卡，导出弹窗进度条会显示到第几段。

如果没装 FFmpeg / 没启动本机服务，剪辑台会明确报错并给出安装指引，
绝不会偷偷用 playbackRate 假效果代替成品。

仓库里的 render_verify.py 是 10 秒短视频验证用例：
  python3 render_verify.py
它会现场生成一段 10 秒测试片（画面亮度随时间由暗到亮 + 440Hz 音频），
自动跑倒放、0.25x / 0.5x / 2x / 5x 变速、倒放+2x 叠加，并逐个检查
导出文件的时长、帧数、音轨以及「首末帧亮度方向」（倒放后必须由亮到暗）。
测试片和导出结果都放系统临时目录，不占用仓库空间。

----------------------------------------------------------
【AI 字幕 / 智能剪口播：为什么会报 Failed to fetch】
网页直接去连第三方 API 时，浏览器会因 CORS（跨域）把请求拦下来，
表现就是「Failed to fetch」。这跟模型能力强弱无关，换任何模型都一样。
另外，把整段 mp4 直接塞给多模态模型也会因为体积过大而失败。

现在的做法：网页把素材交给本机服务，由服务在本机完成抽音轨、切片，
再转发给转写接口 —— 完全绕开浏览器跨域限制，也不会超 20MB。

转写后端按三级自动降级，不需要你手动选：
  ① 本机 faster-whisper（默认 http://127.0.0.1:9000）
     纯本地、免费、最私密，优先级最高；
  ② 你在创作台 / 画布「算力总控 → 第三方API」里填的接口，
     由本机服务转发到 /v1/audio/transcriptions；
  ③ 两者都没有时，剪辑台会给出明确的安装指引，绝不生成假字幕。

★ 模型能力说明（很重要）★
  Claude 全系（含 haiku / sonnet / opus）、普通 GPT、Qwen、DeepSeek、
  Gemini 这类「文本 / 视觉对话模型」走的是 /v1/chat/completions，
  它们能跑「✨ AI剪辑」，但【不是语音转写模型】，也没有 input_audio
  音频输入能力，不能直接做「🅰 AI字幕」。
  AI 字幕需要 whisper-1 / gpt-4o-transcribe 这类转写通道，
  或本机 faster-whisper。若你的第三方服务商没有转写通道，
  网页会明确报 HTTP 404，而不是模糊的 Failed to fetch。

想装本机 faster-whisper（可选，装完全离线可用）：
  Mac / Linux  终端执行：
                 pip install faster-whisper-server
                 faster-whisper-server --port 9000
                （或 pip install faster-whisper uvicorn 后自行起一个
                  兼容 /v1/audio/transcriptions 的服务）
  Windows       在 PowerShell 里执行同样的 pip 命令；
                首次运行会自动下载语音模型（small 约 75MB）。
  装好后重启本服务，剪辑台点「🅰 AI字幕」即会自动优先使用它。

「✂ 剪口播」用的是这次转写顺带算出来的静音气口（FFmpeg silencedetect）
加上字幕文本里的语气词 / 重复句规则，纯本地完成，不调用任何云端 VIP，
也不会把音频发给火山引擎。

----------------------------------------------------------
【粘贴什么链接最稳】
1）最稳妥：以 .mp4 / .webm / .mov / .m4v / .mp3 / .m4a / .wav /
   .jpg / .png / .webp 等结尾的「媒体直链」。
2）抖音：v.douyin.com 短链、www.iesdouyin.com/share/video/...、
   www.douyin.com/video/... 等分享链接，服务会尝试解析出视频直链。
3）B站：含 BV 号的视频页链接或 b23.tv 短链，服务通过 B站公开接口取直链。

如何自己获取直链：浏览器打开视频 → 按 F12 打开开发者工具 →
「网络 / Network」面板 → 筛选 media → 复制那条请求的 URL（以 .mp4 等结尾）。

注意：抖音/B站页面结构与接口经常改版，自动解析可能失效，属正常现象，
改用 .mp4 直链永远最可靠。

【常见故障】
· 启动时提示「端口被占用」：8788 已被别的程序（很可能是另一个本服务
  实例）占用，先关掉旧的终端窗口再重新启动。
· 浏览器里「探测不到本机服务」：确认终端窗口还开着、没被安全软件拦截、
  用的是 https://www.manflows.com 的剪辑台页面。
· 提示「本机未找到 FFmpeg」：按上面的链接安装后，重启本服务（关掉旧窗口
  再双击一次）。
· AI字幕报「Failed to fetch」：说明本机服务没启动而网页走了直连回退。
  双击启动本机服务后重试；跨域问题会消失。
· AI字幕报「转写接口 HTTP 404」：你的第三方服务商没有
  /v1/audio/transcriptions 通道，改用本机 faster-whisper，或换一个有
  whisper-1 / gpt-4o-transcribe 的服务商。
· AI字幕报「没有可用的语音转写后端」：按上一节装 faster-whisper，
  或在创作台/画布里填好支持转写的第三方接口。
· 播放报「上游 403 / 防盗链」：直链过期或需要 Referer，重新解析获取新直链。
· 解析失败：抖音/B站改版或风控，改用 .mp4 直链。
· 转码失败：降低分辨率/码率，或换 H.264 + MP4，并确认录制的中间文件
  本身能正常播放。
· 导出含倒放/变速的片段时提示「需要本机 FFmpeg 真渲染」：按上面章节
  启动本机服务并安装 FFmpeg；仅启动服务但没装 FFmpeg 也一样会提示。
· 真渲染某一段失败：多半是素材比「片段时长 × 倍率」短（素材不够长），
  把片段缩短或调低倍率；也可先把素材下载到本地再导入。
· 倒放后声音听不懂：这是正常的，剪映式倒放就是把音频采样整段反向；
  若不想要倒放音，可把该片段的音频单独静音或改用音频轨处理。
· Mac 双击 .command 无反应：在终端执行 chmod +x 启动本机服务.command。
· Windows 窗口里中文乱码：不影响服务，忽略即可。

----------------------------------------------------------
【隐私说明】
★ 只监听本机（127.0.0.1），不上传任何媒体内容 ★
本服务不对外网开放，不收集、不上传你的视频、音频、字幕或个人数据；
解析/播放时仅按你的请求去访问对应的公网视频服务器（会带上必要的
Referer/User-Agent 以通过防盗链）；导出转码全程由本机 FFmpeg 在本机完成。
AI 字幕的音频切片：走「本机 faster-whisper」时完全不出本机；
只有你主动选择第三方转写接口时，才会把切片发往那一个接口。
临时文件用完立即自动清理，关闭窗口即完全停止。

【接口一览】（供排查，前端会自动调用）
  GET  /api/ping            探测服务、平台、FFmpeg 与本机转写服务状态
  GET  /api/guide           中文帮助
  GET  /api/ffmpeg-install  尝试自动安装静态 FFmpeg
  GET/POST /api/resolve     把分享链接/直链解析成可播放地址
  GET  /api/media?u=...     流式代理媒体（支持 Range、防盗链 Referer）
  POST /api/export          转码导出 / 抽音频 / 生成 GIF
  POST /api/transcribe      抽音轨 + 60 秒分段 + 转写 + 时间码合并 + 静音检测
  POST /api/render          倒放 / 变速逐片段真渲染（后台线程，立即返回 jobId）
  GET  /api/render/status   查渲染进度与结果（?jobId=...）
